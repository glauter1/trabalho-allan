
# API de Pessoas

Projeto acadêmico utilizando Express.js e JSON Server.

## Instalação
npm install

## Executar JSON Server
npm run json-server

## Executar API
npm run dev

## Rotas
GET /pessoas
GET /pessoas/:id
POST /pessoas
PUT /pessoas/:id
DELETE /pessoas/:id

## Filtros
GET /pessoas?idade=30
GET /pessoas?idadeMin=18
GET /pessoas?idadeMax=30
