# API de Pessoas

Projeto acadêmico desenvolvido com Express.js e JSON Server.

## Instalação

npm install

## Iniciar JSON Server

npm run json-server

## Iniciar API

npm run dev

## Rotas disponíveis

GET /pessoas
GET /pessoas/:id
POST /pessoas
PUT /pessoas/:id
DELETE /pessoas/:id

## Filtros disponíveis

GET /pessoas?idade=30
GET /pessoas?idadeMin=18
GET /pessoas?idadeMax=30
